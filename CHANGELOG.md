# Changes

## v0.5 — 27 November 2026

- Reorganized the manuscript as a modular LaTeX project with a BibTeX bibliography and compiled PDF.
- Preserved the original v0.4 Markdown, revision notes, and SVG files under `archive/v0.4/`.
- Kept the view-line interpretation as the main visual thread and retained general FLRW distance/horizon conventions in appendices.
- Added an exact closed-dust background and a smooth localized first-order scalar mass perturbation with global compensation.
- Derived the matter constraints, potential evolution, first-order spatial embedding, normal-observer clock rates, optical ray equations, and source-matched angular/timing comparisons.
- Added reproducible Python calculations, six generated figures, CSV/JSON results, numerical macros, and meaningful analytic/conservation/convergence tests.
- Deferred the Bianchi/global-vorticity research proposal in favor of the local-mass calculation.

The new derivation is a working research result within standard linear perturbation theory. It has not received independent peer review. The model describes growing dust structure, not a fixed compact object or black hole. The numerical examples are dimensionless demonstrations, not fitted astrophysical predictions.
